Adapted component notice — Magic UI "Kinetic Text" (magicui.design)

Source (verified 2026-10-16):
- https://magicui.design/docs/components/kinetic-text
- https://magicui.design/r/kinetic-text.json (registry item `@magicui/kinetic-text`)

Scope: the character-by-character font-weight animation (hovered letter to 900 with a text
stroke, immediate neighbours to 600 and the letters two away to 400) was ported into
`src/shared/KineticText.tsx` + `KineticText.css` for the Lunmi header mark. Adaptations in
this application only: Tailwind arbitrary variants and the `cn` helper were translated to
authored CSS (this project has no Tailwind); TypeScript types were added; a visually hidden
full-text label keeps the word readable for assistive tech. No package dependency is
introduced. Incorporated into this application only — the component itself (including a
ported version) is not offered, sublicensed or redistributed as a component pack.
