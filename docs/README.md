## Documentação local de desenvolvimento

A cópia completa de trabalho tem um índice adicional em `docs/LOCAL-INDEX.md`.
Ele reúne relatórios de desenvolvimento por assunto, planos, contratos de migração,
investigação VoiceOS, entregas alpha, relatório académico e evidências dos ensaios.

Esses arquivos locais podem conter caminhos da máquina, contexto de desenvolvimento ou dados
de teste. Permanecem separados dos guias públicos e não devem ser publicados automaticamente.
As referências aos caminhos anteriores estão registadas em `docs/MAPA-DE-CAMINHOS.tsv`.
